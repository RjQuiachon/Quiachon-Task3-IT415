# Personal IT Portfolio

A responsive static portfolio made with plain HTML, CSS, and JavaScript. It uses a dark navy and blue theme, works by opening `index.html` directly, and can be hosted on GitHub Pages.

## Customize before publishing

1. Edit your name, university, graduation year, email address, and profile links in `index.html` whenever your details change.
2. The profile photo is `assets/0e02a6f5-bc67-4d0e-b154-e83bdbfe1d06.jpg`. If you replace or rename it, update its relative path in `index.html` too.

## Files

- `index.html` contains the page content and section structure.
- `style.css` contains the colors, layout, responsive rules, and hover effects.
- `script.js` controls the mobile navigation and updates the footer year.
- `assets/0e02a6f5-bc67-4d0e-b154-e83bdbfe1d06.jpg` is the profile photo used in the hero section.

No build step or package installation is required.
